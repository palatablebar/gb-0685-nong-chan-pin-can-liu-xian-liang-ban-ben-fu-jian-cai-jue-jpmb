# 检测场景

12个苹果样本分4批，每个样本初检P01为<0.01mg/kg，采样日标准限量0.005，因此不确定。次日同样本同方法复检0.004且LOD0.001，判为PASS并替代原报告。每样本P02为30ug/kg，超过0.02mg/kg，仍FAIL。最终24项目，12PASS、12FAIL，四批均FAIL。脏批额外含缺LOD、同版冲突、错列、空行与重复表头。

## 修订场景

批次签字出证后，上游更正限量：P01采样日窗口限量由0.005收紧为0.003（APL-P01-V2C），P02由0.02放宽为0.04。同时B001批三个样本晚到有效复检报告（00037-00039，关联各自初检链，P01定量0.002）。修订后：P02各项FAIL→PASS；无晚到报告的P01各项PASS→FAIL；B001的P01经复检保持PASS，全批升级为PASS，其余批保持FAIL但驱动项目易位。更正限量表缺P02行则修订失败，旧版结论保持有效。
